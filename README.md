# Cinematic Studio Showcase

Build a premium creative portfolio website inspired by this Framer reference:

https://prysmtemplate.framer.website/

I want to recreate the overall layout, visual rhythm, navigation structure, spacing, typography hierarchy, scrolling behavior, transitions, hover interactions, and animation language of the reference site, while creating an original portfolio for my own creative studio.

Important

Do NOT simply create a generic portfolio website.

The reference is the primary design and interaction inspiration. Study its structure and recreate the experience as closely as practical, but use original content, assets, and branding.

Technology

Build the site using a clean, modern web stack that can be easily exported and committed to GitHub.

Prefer:

HTML

CSS

JavaScript

GSAP where useful for advanced animations

No unnecessary frameworks or dependencies

If a framework is genuinely beneficial, use React only when it provides a clear advantage.

The final project must:

Have a clean and understandable file structure

Run locally without complicated setup

Be easy to edit manually

Be GitHub-ready

Avoid proprietary Framer code or dependencies

Avoid unnecessary libraries

Keep animations performant

Website structure

Create these main sections:

HOME

Minimal navigation

Large typographic hero

Strong visual introduction

Large featured visual/video area

Smooth scroll-based transitions

Selected work section

Short studio introduction

Contact CTA

WORK

Premium project grid/list inspired by the reference

Large project previews

Project title

Category

Year

Hover interactions

Smooth image/video transitions

PROJECT DETAIL PAGES
Each project should have:

Large hero image/video

Project title

Client

Year

Services

Short project description

Large visual sections

Video support

Image galleries

Credits

Previous/next project navigation

ABOUT

Short studio introduction

Capabilities

Experience / clients

Tools or disciplines

Selected statistics if appropriate

Contact CTA

CONTACT

Minimal, editorial layout

Email

Social links

Strong closing statement

Visual direction

The site should feel:

Minimal

Premium

Editorial

Cinematic

Sophisticated

Contemporary

Art-directed

High-end creative studio

Avoid:

Generic SaaS aesthetics

Excessive rounded cards

Gradients everywhere

Excessive shadows

Generic UI components

Template-like layouts

Overly complicated navigation

Unnecessary decorative elements

Use generous whitespace, strong typography, large imagery, restrained UI, and deliberate composition.

Animation and interaction

This is very important.

I want the site to feel as close as possible to the interaction quality of the Framer reference.

Pay particular attention to:

Page-load animation

Typography entrance animations

Smooth scrolling

Scroll-based reveals

Image movement/parallax

Project hover interactions

Image scaling

Cursor interactions where appropriate

Navigation transitions

Page transitions

Smooth project-to-project navigation

Subtle micro-interactions

Animations should feel slow, controlled, cinematic and intentional, not flashy.

Use easing and timing carefully.

Do not animate everything.

Responsive design

The website must be designed intentionally for:

Desktop

Tablet

Mobile

Do not simply shrink the desktop layout.

Adapt typography, spacing, navigation, image ratios, project layouts, and animations for mobile.

Mobile performance is important, especially because the portfolio will contain large images and video.

Content

Use realistic placeholder content for now.

The portfolio represents a premium CGI / product visualization / product film studio.

The positioning should communicate:

CGI
Product Visualization
Product Films
Art Direction
Visual Development
Creative Direction

The website should make the studio feel capable of working with premium technology, automotive, lifestyle, and consumer product brands.

Code quality

Before finishing:

Organize the code clearly

Separate reusable components

Keep CSS maintainable

Use semantic HTML

Optimize images

Lazy-load media where appropriate

Optimize videos

Avoid unnecessary dependencies

Make all major content easy to replace

Add comments only where they are useful

Make sure there are no broken links or console errors

Final goal

The result should feel like a real premium creative studio website, not an AI-generated template.

Prioritize:

Design fidelity to the reference

Animation quality

Typography

Spacing and composition

Image presentation

Responsive behavior

Performance

Clean, GitHub-ready code

Build the homepage first and establish the visual system before expanding the remaining pages.
